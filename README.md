# Evil Tower 2

Карточный рогалик про подъём по башне (Phaser 3 + TypeScript + Vite) для Яндекс Игр. Портретная мобильная раскладка 720×1280, на десктопе — по центру окна. Реализовано по GDD (`EvilTower2 GDD.pdf`) и дереву навыков (`tools/tower_class_trees.drawio`).

## Запуск

Нужен Node.js LTS (20.19+ / 22+).

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # проверка типов + сборка в dist/
npm run zip        # evil-tower-2.zip — архив для консоли разработчика Яндекс Игр
```

Полезные скрипты:

| Команда | Что делает |
|---|---|
| `npm run skilltree` | Пересобирает `src/data/skillTree.json` из `tools/tower_class_trees.drawio` |
| `npm run sim -- warrior 50` | Симулятор баланса: бот проходит 15 комнат с фармом, выводит win-rate и время (`warrior/mage/archer/mercenary`) |
| `npm run store` | Генерирует иконку 512×512 и обложку 800×470 в `store/` (нужен `pip install pymupdf`) |
| `npm run typecheck` | Только проверка типов |

Dev-параметры URL (работают только в `npm run dev`, в сборку не попадают):
`/?reset=1&class=mage&gold=5000&souls=20000&clear=8&tut=1&autoskill=200&weapon=2&armor=1`

## Структура

```
src/
  config.ts            константы: размеры, тайминги из GDD, реклама
  data/                классы, перки (56), предметы, враги и комнаты, экономика, достижения, skillTree.json
  logic/               чистая логика без Phaser: skillTree, stats, run (поле 3×3, бой), autoUse, autoSkill, traits — её же гоняют симулятор и selftest
  systems/             Store (сохранения), Audio (процедурный звук), Ads
  sdk/YandexSDK.ts     обёртка SDK Яндекс Игр + заглушка для локальной разработки
  i18n/                RU/EN, ключи типизированы
  ui/                  Kit (кнопки-плашки, диалоги, валюта, скролл), Textures, PixelArt, SvgIcons, HeroCard, Popups
  scenes/              Boot, ClassSelect, Hub, Shop, Levels, Settings, SkillTree, Game, Achievements
tools/                 конвертер drawio, симулятор, генератор материалов, упаковщик zip
store/                 иконка/обложка каталога и текст карточки игры (listing.md)
```

## Как подставить свои картинки, названия и перки

- **Иконки/спрайты (jpg/png/bmp/webp):** положите файл в `src/assets/images/` с именем ключа — он подхватится сам, иначе рисуется заглушка. Ключи: `hero_<classId>`, `cls_<classId>`, `enemy_<id>`, `perk_<perkId>`, `item_w_<lineage>_<tier>`, `item_a_<tier>`, `item_potion_heal|regen`, `item_artifact`, `ico_gold`, `ico_soul`, `spr_chest`, `spr_gold`, `bg_stone`.
- **Перки:** одна запись в `src/data/perks.ts` = id, иконка, название, описание (по умолчанию собирается из `effects`), эффекты. Типы эффектов перечислены в `PerkEffect`.
- **Баланс:** враги и комнаты — `src/data/levels.ts`, цены узлов/награды — `src/data/economy.ts`, оружие/броня — `src/data/items.ts`, зелья и шансы выпадения из сундуков (`GAMEPLAY`) — `src/config.ts`. После правок запустите `npm run sim`.
- **Правила добычи:** души начисляются сразу и остаются при поражении; золото копится в «кошеле» комнаты и зачисляется только за победу. Сундук даёт золото и с шансом 65 % расходник (ещё один — 20 %). Зелье восстановления полностью заполняет ресурс класса и на 5 ходов ускоряет его набор.
- **Крит:** множитель плавающий — каждый крит бьёт по-новому в диапазоне `GAMEPLAY.critMulMin … critMulMax` (`src/config.ts`); перки «крит. урон» сдвигают оба края. Фиксированного «×1.5» в игре нет.
- **«Играть»** в хабе всегда ведёт в новейшую открытую комнату; старые комнаты запускаются из «Уровней».
- **Автоматизация** (без окон настроек; подсказка — наведение мыши или долгое нажатие): на поле боя под каждым расходником — маленькая плашка «АВТО» (`src/logic/autoUse.ts`: лечение, когда не хватает объёма зелья или следующий ответный удар опасен; восстановление, когда ресурса нет на удар/выстрел и не хватает ≥ 60 % шкалы; артефакт — когда убьёт 3+ врагов). В шапке дерева навыков — одна кнопка автопрокачки (`src/logic/autoSkill.ts`): когда она включена, купленная вручную характеристика задаёт ветку (`inferBranch`), и вся ветка вниз докупается на все имеющиеся души, включая перки-«ворота»; на развилках берётся тот стат (основной или особый), что игрок выбрал в последний раз. Перед метаморфозой автопрокачка останавливается — смена класса всегда решение игрока. Настройки хранятся в сохранении (`SaveData.auto`).
- **Метаморфозы и смена класса:** в окне выбора класса одна запись на линейку — улучшенный класс *заменяет* прежний (наёмник → ассасин), вернуться к прежнему классу выбором нельзя (`currentClassOf` в `src/logic/skillTree.ts`). «Отмена метаморфозы» осталась только как функция дерева навыков (возврат части душ).
- **Переходы между экранами** (`src/ui/Kit.ts`): меню открывается «окном», вырастающим из своей кнопки (`zoomOut` → `zoomIn`), возврат в хаб сжимает окно обратно в кнопку; бой, выбор класса и хаб входят «наездом» камеры (`fadeToScene` + `dollyIn`); содержимое экранов появляется каскадом (`staggerIn`), вкладки Лавки — со скользящей подсветкой и въезжающими строками. Длительности — `TIMING.menuZoom`.
- **Краткие сводки классов** строятся из данных класса и его стартового перка (`src/logic/traits.ts`), поэтому не расходятся с балансом; пороги — `TRAIT_LIMITS`.
- **Оформление:** цвета характеристик — `STAT_COLOR` (`src/ui/Textures.ts`), шрифты/тайминги пульсации — `src/config.ts` (`COLOR`, `FONT_*`, `TIMING`), все кнопки, плашки, подсказки, диалоги и анимации переходов — `src/ui/Kit.ts`.

## Шрифты и лицензии

Заголовки — **Alegreya SC**, интерфейс и числа — **Nunito**; оба под SIL Open Font License 1.1 (свободно, в том числе в коммерческих играх), подключены через пакеты `@fontsource/*` и входят в сборку. Тексты лицензий лежат в `public/licenses.txt` и попадают в архив. Как выбирали: из каталога Google Fonts/Fontsource отобрали шрифты с лицензией OFL **и кириллицей** (Cinzel, Marcellus и другие «фэнтезийные» без кириллицы отпали), сравнили на реальных строках игры — Philosopher, Alegreya SC, Spectral SC, Yeseva One для заголовков и Nunito, Rubik, Golos Text, Fira Sans Condensed, Onest, Alegreya Sans для интерфейса. Alegreya SC даёт книжно-фэнтезийный характер и хорошо держит обводку; у интерфейсных кандидатов мелкий текст и цифры читались не лучше Nunito, поэтому он остался.
- **SVG-иконки** (чёрные, по GDD): `src/ui/SvgIcons.ts`.

## Яндекс Игры

- SDK подключается только в сборке (`/sdk.js` внедряется плагином Vite); локально работает заглушка.
- Реализовано: `LoadingAPI.ready()`, `GameplayAPI.start/stop`, события паузы/возобновления, `getPlayer().getData/setData` (облачные сохранения + localStorage, побеждает более свежее), rewarded video (воскрешение, ×2 награда, ×2 ежедневная награда, дар башни), interstitial в паузах (не раньше 3-й комнаты, кулдаун 3 мин), язык из `environment.i18n.lang`, лидерборд `rooms` и статистика.
- В консоли разработчика создайте лидерборд с именем `rooms` (опционально) и отметьте использование облачных сохранений.
- Соответствие модерации: звук глушится при потере фокуса и во время рекламы, нет контекстного меню/выделения текста/скролла страницы, прогресс сохраняется сразу, архив < 1 МБ, `index.html` в корне, имена файлов без пробелов и кириллицы (проверяет `npm run zip`).
- Карточка игры: тексты, теги и чек-лист — `store/listing.md`.
