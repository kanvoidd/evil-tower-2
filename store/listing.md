# Карточка игры для консоли разработчика Яндекс Игр

**Название (одинаково в игре и материалах):** Evil Tower 2

## Краткое описание (RU)
Карточный рогалик: поднимайтесь по башне, бейте монстров на поле 3×3, собирайте золото и души, открывайте классы и легендарные перки.

## Полное описание (RU)
Evil Tower 2 — средневековый рогалик в духе карточных игр. Ваш герой — карточка на поле 3×3: нажмите на соседнюю карту, чтобы атаковать врага, собрать золото или открыть сундук. Победили врага — заняли его место, а поле тут же пополняется новой картой.

• 4 стиля боя: Воин, Маг, Лучник и Наёмник — у каждого своя механика (выносливость, мана, концентрация, осмотрительность).
• Огромное дерево развития: сотни улучшений, развилки, метаморфозы в Рыцаря, Берсерка, Паладина, Некроманта, Ассасина, Ниндзя и других.
• Лавка с оружием и бронёй, которые изнашиваются, и зельями.
• Три этажа башни с боссами, случайные карты в каждой комнате.
• Ежедневные награды и подарки башни.

Управляется одним пальцем. Играйте с телефона или компьютера.

## Description (EN)
Evil Tower 2 is a medieval card roguelike. Your hero is a card on a 3×3 field: tap a neighboring card to attack, loot gold or open a chest. Defeat an enemy and take its place — a new card appears instantly. Four fighting styles (Warrior, Mage, Archer, Mercenary), a huge skill tree with class metamorphoses, breakable gear, three floors with bosses, and daily rewards. One-finger controls, mobile and desktop.

## Возрастной рейтинг

## Материалы
- Иконка: `store/icon-512.png` (512×512) — сгенерирована из спрайтов игры (`npm run store`), без рамок/скруглений/интерфейса.
- Обложка: `store/cover-800x470.png` (800×470).
- Скриншоты (не менее 70% реального геймплея): 4–6 портретных кадров — поле боя с подсказкой, дерево навыков, экран победы, башня уровней, лавка. Снимайте из `npm run dev` в эмуляции телефона.
- Видео: 15–20 с геймплея (бой → монеты → покупка узла → метаморфоза).
- Пока арт — заглушки. Для CTR замените спрайты на финальный арт (`README.md` → «Как подставить свои картинки») и пересоберите обложку с персонажем крупным планом.

## Чек-лист перед отправкой на модерацию
- [ ] `npm run build && npm run zip`, загрузить `evil-tower-2.zip` как HTML5-игру.
- [ ] В консоли включить облачные сохранения; создать лидерборд `rooms` (опционально).
- [ ] Проверить черновик на телефоне и в десктопном браузере (ориентация — портрет).
- [ ] Заполнить описание/теги/категории, загрузить иконку, обложку, скриншоты.
